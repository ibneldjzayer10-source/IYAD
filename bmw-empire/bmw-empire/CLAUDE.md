# BMW Empire — دليل النظام

حساب إنستغرام (بدون وجه) متخصص في سيارات BMW: تاريخها، محركات S58/B58، سباقات M-Power.
النظام يعمل محلياً بأدوات مجانية وينشر الريلز عبر Late API (`LATE_API_KEY` في `.env`).

## هوية BMW M (إلزامية في كل تصميم)
| اللون | HEX | الاستخدام |
|---|---|---|
| أزرق فاتح | `#00A0E9` | الكلمة المميزة في الترجمة، الشعار |
| أزرق داكن | `#003366` | إطار النص، الخلفيات |
| أحمر | `#E2001A` | التشويق والأرقام المهمة |

## هيكلية المجلدات
`01_raw_media` مصادر خام ← `02_transcripts` نصوص ← `03_sliced_clips` مقاطع وسيطة ← `04_final_reels` النهائي ← `05_published` المنشور
`assets/` (logo.png، fonts/، music/، broll/ بأسماء مثل S58.png) · `commands/` المهارات الـ20

## التشغيل
`pip install -r requirements.txt` (+ تثبيت ffmpeg) ثم `python run_pipeline.py`
اختبار بلا نشر: `python run_pipeline.py --dry-run` · خطوة واحدة: `--only 5`

## ترتيب التنفيذ
01→02→03→04→05→06→07→09→10→12→08→11→13→14→15→16→17→18→20 (و19 عند الطلب)

## قواعد المحتوى
- لا يُحمَّل ولا يُنشر إلا محتوى رخصته Creative Commons أو مصدر وافقت عليه صراحةً في `approved_urls.txt` (الخطوة 04 تفحص وتُصدر rights_report.json؛ والمنع عبر RIGHTS_ENFORCE=1 في سكربت النشر).
- كل ريل يضم تعليقاً صوتياً أصلياً + معلومات تقنية، ويُذكر المصدر في الوصف عند الحاجة.
- الأرقام التقنية في الخطوة 06 مرجعية تقريبية: راجعها قبل النشر.
- النبرة: حماسية، مختصرة، خبير سيارات. السؤال التفاعلي أول سطر في الوصف.
- لا تنشر أكثر من `MAX_POSTS_PER_RUN` ريلز في التشغيلة.
